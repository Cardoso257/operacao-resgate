# Central de Achados — Projeto de investigação

Este repositório não inclui `lib/firebase_options.dart`: copie o arquivo GERADO pelo FlutterFire CLI do projeto Firebase da escola. Também é necessário ativar Authentication > Google, cadastrar o domínio autorizado e configurar as regras do Firestore para a aula. Execute preferencialmente no Chrome.

Se criar um projeto novo: `flutter create central_achados` e copie `lib`, `pubspec.yaml` e demais arquivos deste ZIP para a pasta do projeto. Em seguida rode `flutter pub get` e `flutter run -d chrome`.

**Aviso:** o projeto dos alunos contém defeitos intencionais. Não exponha dados pessoais reais em atividades com Firestore de teste.
